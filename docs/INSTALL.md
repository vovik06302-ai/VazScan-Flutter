# VAZ Scan: установка и первый запуск

## Что понадобится
- Телефон на Android 8.0 или новее.
- Адаптер ELM327 с Bluetooth (не Wi-Fi).
- Автомобиль с разъёмом OBD-II (ВАЗ 2110 и новее, большинство машин после 2000-х).

## 1. Установка приложения
1. Скачайте APK из последнего релиза на GitHub (раздел Releases).
2. Откройте файл на телефоне. Если телефон попросит, разрешите установку из этого источника.
3. Нажмите «Установить».

## 2. Русский голос (для озвучки)
Настройки телефона → Синтез речи → Google Text-to-Speech → Установка голосовых данных → Русский.
Без него приложение молчит, но остальные функции работают.

## 3. Подключение адаптера
1. Вставьте ELM327 в разъём OBD-II под рулём до упора. Адаптер не должен болтаться.
2. Включите зажигание (двигатель можно не заводить для чтения ошибок).
3. В настройках Bluetooth телефона сопрягите адаптер. PIN: 1234 или 0000.

## 4. Первый запуск
1. Откройте VAZ Scan, прочитайте предупреждение и нажмите «Понятно».
2. Вкладка «Связь» → «Найти адаптер» → выберите ваш адаптер → «Подключить».
3. Дождитесь «Подключено к ЭБУ». Первое подключение может занять до минуты.
4. «Проверка адаптера» покажет, стабильна ли связь.

## 5. Диагностика
- «Диагностика» → «Полная диагностика». Для полной картины заведите двигатель и прогрейте его до 80 °C.
- Ошибки, причины и действия: вкладка «Ошибки».
- Датчики в реальном времени: вкладка «Датчики». Красный цвет означает тревогу.

## Важно
- Если тревога красная, не ездите. Остановитесь в безопасном месте.
- Перед сбросом ошибок сохраните отчёт (История → PDF).
- Рекомендации ориентировочные. Решения о ремонте принимает специалист.
